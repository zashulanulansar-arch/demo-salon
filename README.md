# SAHAR — Beauty Salon Demo

Демонстрационный адаптивный сайт салона красоты SAHAR в Кокшетау.

## Запуск локально
Откройте `index.html` в браузере.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите `main` и папку `/ (root)`, затем Save.

## Перед публикацией
Проверьте контактные данные, адрес, ссылки и замените демонстрационные фотографии на одобренные владельцем салона.
